# MEAN Stack - Full-Stack Development Guide

## Purpose

Technology-specific guidance for MEAN Stack (MongoDB, Express, Angular, Node.js) development workflows.

## Project Structure

```
mean-project/
├── backend/              # Express/Node.js
├── frontend/             # Angular
└── shared/
```

## Commands

```bash
# Run both
npm run dev

# Backend
cd backend && npm run dev

# Frontend
cd frontend && ng serve
```

## Quick Reference

| Action | Command |
|--------|---------|
| Install all | `npm run install` |
| Dev both | `npm run dev` |
