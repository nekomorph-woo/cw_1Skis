# Nuxt.js - Vue Framework Guide

## Purpose

Technology-specific guidance for Nuxt.js (Vue SSR framework) development workflows.

## Technology Detection

**Detect Nuxt when:**
- `nuxt.config.ts`
- `pages/` directory (file-based routing)
- `package.json` with `nuxt`
- Auto-imports for components and composables

---

## Quick Reference

| Action | Command |
|--------|---------|
| Dev | `npm run dev` |
| Build | `npm run build` |
| Generate | `nuxt generate` |
