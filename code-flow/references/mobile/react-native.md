# React Native - Mobile Development Guide

## Purpose

Technology-specific guidance for React Native mobile development.

## Commands

```bash
# Start Metro bundler
npm start

# Run on iOS
npm run ios

# Run on Android
npm run android

# Start with Expo
npx expo start
```

## Quick Reference

| Action | Command |
|--------|---------|
| Install | `npm install` |
| Start | `npm start` |
| iOS | `npm run ios` |
| Android | `npm run android` |
