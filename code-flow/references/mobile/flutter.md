# Flutter - Mobile Development Guide

## Purpose

Technology-specific guidance for Flutter mobile development.

## Commands

```bash
# Run app
flutter run

# Run on specific device
flutter run -d <device-id>

# Build APK
flutter build apk

# Build iOS
flutter build ios

# Run tests
flutter test
```

## Quick Reference

| Action | Command |
|--------|---------|
| Run | `flutter run` |
| Build APK | `flutter build apk` |
| Build iOS | `flutter build ios` |
| Test | `flutter test` |
| Clean | `flutter clean` |
