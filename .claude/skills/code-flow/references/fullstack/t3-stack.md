# T3 Stack - Modern Full-Stack Guide

## Purpose

Technology-specific guidance for T3 Stack (TypeScript, tRPC, Tailwind, Next.js) development workflows.

## Tech Stack

- **Next.js** - React framework
- **TypeScript** - Type safety
- **tRPC** - End-to-end typesafe APIs
- **Tailwind CSS** - Styling
- **Prisma** - ORM (optional)

## Commands

```bash
# Development
npm run dev

# Build
npm run build

# Start
npm start
```

## Quick Reference

| Action | Command |
|--------|---------|
| Dev | `npm run dev` |
| Build | `npm run build` |
| DB Push | `npx prisma db push` |
