## Risk Management

### Risk Register

| 风险 | 影响 | 概率 | 评分 | 缓解措施 | 负责人 |
|------|--------|-------------|-------|------------|-------|
| AI 生成质量不稳定 | 高 | 中 | 高 | 强约束 DSL + 代码模板 | 开发者 |
| 开发进度延期 | 中 | 中 | 中 | 预留缓冲时间 | 项目经理 |
| 浏览器兼容性问题 | 高 | 低 | 中 | 提供兼容性检测 | 开发者 |
| 内存占用过高 | 中 | 中 | 中 | 实现自动销毁机制 | 开发者 |

### Contingency Plans

| 场景 | 触发条件 | 响应 |
|----------|---------|----------|
| 开发进度延期 | 阶段延期超过 3 天 | 调整里程碑，削减非核心功能 |
| AI API 故障 | API 连续失败 > 1 小时 | 切换备用模型或维护模式 |
| 内存溢出 | 内存占用 > 1GB | 强制销毁旧标签，提示用户 |

### Glossary

| 术语 | 定义 |
|------|------------|
| Kura (蔵) | 日语"仓库"的意思，项目名称 |
| 微应用 | 小型、独立的 Web 应用 |
| 壳应用 | 容器应用，负责管理和运行微应用 |
| DOM 锚定 | 点击界面元素获取代码片段 |
| @shared | 公共模块的虚拟路径前缀 |
| Vibe Creating | 通过 AI 快速创建应用 |
| Vibe Coding | 通过 AI 快速修改代码 |
